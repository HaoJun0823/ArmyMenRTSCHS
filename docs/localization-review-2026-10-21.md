# 单位术语校对与 PS2 移植资料回馈

贡献者：[木下萌子 / MoekoSama](https://github.com/MoekoSama)。原 PC 汉化作者与项目许可保持不变。实现、逆向分析与文档整理使用 Codex 辅助，单位术语另由 GPT-6 Luna 校对，最终采用项结合原版 PS2 对象配置复核。

## PC 版可以直接审查的修改

| 英文/条目 | 原译 | 建议采用 | 原因 |
|---|---|---|---|
| Medic | 医疗兵 | 医疗吉普车 | 对应机械载具，由车库生产，原译容易误认作步兵。 |
| Mine Sweeper | 扫雷车 | 扫雷兵 | 对应步行生物单位、步兵装甲，由兵营生产。 |
| Guard Tower | 哨塔 | 警卫塔 | 与教程、战役目标中的同一建筑名称统一。 |
| Resource Depot | 资源库 | 资源站 | 与教程中的名称统一。 |
| PC 教程里的 Scorch | 斯考奇 | 焦炭 | 统一到现有单位显示名；不重新命名其他人物或绰号。 |

`translate/merged.json` 和对应的 `part*.out.tsv` 同步修改，保持全部 846 个键、英文源文、顺序和控制符。`translate/chars.txt` 仅在末尾追加新出现的“吉”，不重排原有字形。

**制作 PC 发布包前，必须用更新后的字符表重新生成各字号字库页和索引，并重新打包文本。** 本提交只交付源码和文本，不伪称旧的预生成字库已经包含“吉”。PC 插件、ASI Loader、预生成字体和部署目录均未修改。

校验命令（在 Git 仓库根目录运行）：

```console
python Tools/verify_localization_review.py
```

目前 `_build_full.py` 依赖作者本地的 `dat_tool.py` 和原版文本 JSON，仓库中未提供这些输入。没有擅自重写该工具链，也没有声称做过 PC 版实际运行验证。上游 JSON/TSV 中的反斜杠转义原样保留；PS2 最终二进制中的四处换行修复不等同于可以直接替换 PC 源表里的所有转义。

## 单独整理的 PS2 材料

见 [PS2 交接说明](../ports/ps2/README.md)。包括 PS2 专用教程修订、GBK 解码/测宽/绘制/换行钩子、字形与镜像资源检查代码，以及按版本区分的验证结论。这些内容放在 `ports/ps2/`，不进入 PC 插件运行路径。

PS2 导出代码是供审阅和继续移植的参考快照，不是已经重新验收的独立构建发行包。游戏镜像、原版 ELF/数据/字体、Windows 字体、已栅格化字体、BIOS、存档、完整内存转储和本机凭据都不在提交中。
